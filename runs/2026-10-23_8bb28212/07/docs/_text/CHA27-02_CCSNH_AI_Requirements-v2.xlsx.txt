Data Privacy & Security (FERPA) |  | 
·         Strict No-Training Policy  [Required] |  | 
Vendor MUST guarantee that CCSNH Data (prompts, uploads, outputs) is NOT used to train, fine-tune, or improve foundation models or third-party models. |  | 
·         Zero Data Retention / Session Only Processing  [Required] |  | 
Option to configure sessions where data is processed in memory and not retained by the vendor after the session ends. |  | 
·         FERPA Compliance  [Required] |  | 
Solution must be capable of acting as a official under FERPA; compliant handling of Education Records. |  | 
·         Data Residency  [Required] |  | 
All data at rest and in transit must remain within the United States. |  | 
·         Security Certification  [Required] |  | 
Vendor must provide a current SOC 2 Type II report or ISO 27001 certification. |  | 
·         Data Isolation  [Required] |  | 
Data supplied by one user must not be accessible to or influence the experience of any other user (unless explicitly shared in a team workspace). |  | 
Intellectual Property |  | 
·         Ownership of Inputs and Outputs  [Required] |  | 
CCSNH and its users retain full ownership of all prompts, uploaded content, and AI-generated outputs. |  | 
·         Copyright Indemnification  [Required] |  | 
Vendor must indemnify CCSNH against third-party claims of copyright infringement regarding the authorized use of the platform's outputs. |  |
